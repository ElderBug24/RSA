# RSA CLI

## This project is a command line interface, programmed in <ins>Rust</ins> that allows its user to: 
  - Generate a set of keys
    - Automatically and randomly
      - And show numbers involved in different steps of the process
    - Based on numbers chosen by the user
  - Encrypt / Decrypt data
    - From user input
    - From a file
  - Save data to a file
